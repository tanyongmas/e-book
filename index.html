ตั้งค่าเชื่อมต่อ Google Apps Script API

คัดลอก Web App URL ที่ได้จากการกด **Deploy (การทำให้ใช้งานได้)** ใน Google Apps Script มาวางตรงนี้เพื่อเชื่อมต่อกับ Google Sheets & Google Drive

ขั้นตอนตั้งค่า Google Sheets & Drive API (5 นาที)

💡 ฟรี 100% ไม่เสียค่าบริการ Server
ระบบนี้ใช้ Google Workspace (Google Drive + Sheets) ทำหน้าที่เป็นฐานข้อมูลและระบบจัดเก็บไฟล์ในตัว
  1. สร้าง Google Sheet ใหม่:
    เข้า sheets.new บน Google Drive ของคุณ
  2. เปิด Apps Script Editor:
    ไปที่เมนูด้านบนเลือก ขยายส่วนต่าง ๆ (Extensions) ➔ Apps Script
  3. คัดลอกสคริปต์ไปวาง:
    ลบโค้ดเดิมออกทั้งหมด แล้วกดปุ่มด้านล่างเพื่อคัดลอกสคริปต์ Code.gs ไปวางในกล่องข้อความ
  4. กด Deploy (การทำให้ใช้งานได้):
    กดมุมขวาบน การทำให้ใช้งานได้ (Deploy) ➔ การทำให้ใช้งานได้รายการใหม่ (New Deployment)
    - เลือกประเภท: เว็บแอป (Web App)
    - การอธิบาย: WebE-Book API
    - ผู้มีสิทธิ์เข้าถึง: ทุกคน (Anyone) *(สำคัญมาก)*
  5. นำ URL มาวางในเว็บ:
    คัดลอก URL ของ Web App ที่ได้ นำมาใส่ในปุ่ม "ตั้งค่า API" ในแผงแอดมิน
